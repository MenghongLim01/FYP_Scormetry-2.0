# Lucidchart Mermaid Import Pack

Use these `.mmd` files to recreate the Chapter 3 diagrams in Lucidchart. Each `.mmd` file contains Mermaid diagram code for one figure. Lucidchart can generate an editable diagram from Mermaid code, so you can paste each file into Lucidchart and then adjust spacing, colors, fonts, and layout before inserting the diagram into your capstone document.

## Folder Contents

- `fig-01.mmd` to `fig-32.mmd` contain the Mermaid code for each figure.
- `README.md` explains how to import the diagrams into Lucidchart.

## Recommended Lucidchart Workflow

1. Open Lucidchart in your browser.
2. Create a new blank Lucidchart document.
3. Rename the document to `Scormetry 2.0 Chapter 3 Diagrams`.
4. Create one Lucidchart page per figure, or place multiple small diagrams on one page if you prefer.
5. Start with `fig-01.mmd`, then continue in order until `fig-32.mmd`.

## How to Import One Diagram

1. Open the `.mmd` file for the figure you want to import.
   - Example: open `fig-01.mmd` for `Fig. 1. Organisational Chart for Scormetry 2.0`.
2. Select all code in the file.
3. Copy the code.
4. In Lucidchart, find the Mermaid or diagram-from-code option.
   - The option may appear as `Mermaid`, `Generate from Mermaid`, `Import Mermaid`, or `Diagram as Code`, depending on your Lucidchart interface.
5. Paste the copied Mermaid code into the Lucidchart Mermaid editor.
6. Click the generate/import button.
7. Review the generated diagram.
8. Rename the Lucidchart page or diagram using the exact figure caption.
9. Adjust the layout if needed.
   - Increase spacing between shapes.
   - Align boxes neatly.
   - Keep captions and labels readable.
   - Use consistent fonts and line weights.
10. Export the final diagram as PNG or SVG.
11. Insert the exported image into your Word document under the correct figure number and caption.

## Suggested Export Settings

- Use PNG if you only need to insert the diagram into Word quickly.
- Use SVG if you want sharper quality and better scaling.
- Use a white background for formal document consistency.
- Keep the diagram width consistent across figures.
- Use the same font style across all diagrams if Lucidchart allows editing.

## Important Notes

- Mermaid code is not the final image. It is source code that Lucidchart converts into a diagram.
- If Lucidchart says the code has an error, check whether the full file was copied. Missing the first or last line can break the diagram.
- If a generated diagram looks crowded, manually spread out the boxes in Lucidchart.
- For Word insertion, place the figure image first, then add the caption below it.
- Do not rename figure numbers unless you also update the List of Figures in the capstone document.

## If Lucidchart Mermaid Is Not Available

If your Lucidchart account does not show a Mermaid import option:

1. Open https://mermaid.live.
2. Paste the `.mmd` code into the Mermaid editor.
3. Export the diagram as PNG or SVG.
4. Insert the exported diagram into Word.
5. If needed, recreate the diagram manually in Lucidchart using the exported image as a guide.
